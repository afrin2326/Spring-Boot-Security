# Spring Boot Security Practice

This repository contains practice projects focused on authentication and security features in Spring Boot applications. The projects demonstrate different approaches to form-based authentication, password management, JWT, OAuth2, and token-based security.

## Projects

| No. | Project Name                                          | Description                                                           |
| --- | ----------------------------------------------------- | --------------------------------------------------------------------- |
| 1   | `SpringBootSecurityFormBasedAuth`                     | Implements form-based authentication using Spring Security.           |
| 2   | `SpringBootSecurityFormBasedAuthUsingViewPage`        | Demonstrates form-based authentication with a custom login view.      |
| 3   | `SpringBootSecurityJSON_Web_Token`                    | Explores JSON Web Token (JWT)-based authentication.                   |
| 4   | `SpringBootSecurityOAuth`                             | Demonstrates OAuth-based authentication and authorization.            |
| 5   | `SpringBootSecurityWebBasedAuthAutoPassword`          | Explores web authentication with an automatically generated password. |
| 6   | `SpringBootSecurityWebBasedAuthCustomPassword`        | Demonstrates authentication with a custom password.                   |
| 7   | `SpringBootSecurityWebBasedAuthCustomPassword2`       | Provides another implementation of custom-password authentication.    |
| 8   | `SpringBootSecurityWebBasedAuthCustomPassword3`       | Further explores custom authentication configuration.                 |
| 9   | `SpringBootSecurityWebBasedAuthCustomPasswordEncoder` | Demonstrates password encoding with Spring Security.                  |
| 10  | `SpringBootSecurityWebBasedToken1`                    | Explores token-based authentication in a web application.             |

## Technologies Used

* Java
* Spring Boot
* Spring Security
* Maven
* JSON Web Token (JWT)
* OAuth2
* HTML and Thymeleaf (where applicable)

## Concepts Covered

* Authentication and authorization
* Form-based login
* Custom login pages
* Password encoding
* Generated and custom passwords
* JWT authentication
* OAuth2 authentication
* Security configuration in Spring Boot

## Prerequisites

* JDK compatible with the project's Spring Boot version
* Maven
* An IDE such as Spring Tool Suite (STS) or IntelliJ IDEA
* A basic understanding of Java and Spring Boot

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/afrin2326/Spring-Boot-Security.git
   ```

2. Open the desired project folder in your IDE.

3. Check the project's `pom.xml` and application configuration.

4. Configure any required environment variables or application properties.

5. Run the Spring Boot application using the IDE or Maven.

**Note:** Each project is a separate practice application. Dependencies, configuration, and setup requirements may differ between projects.

## Repository Structure

Each project is maintained in its own directory so that its implementation can be explored independently.
